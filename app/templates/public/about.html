About Smart Study

An intelligent study planner for students from Class 8 to Master level — Final Year Project by Hemant Kumar Sah (NP069826).

Mission

Help students systematically manage academic workload by identifying performance trends and generating actionable, data-driven study schedules powered by machine learning.

Built For

APU computing students — especially those balancing multiple subjects with varying difficulty, attendance patterns, and exam performance across semesters.

Technology Stack
Backend
Flask · SQLAlchemy · Flask-Login · Bcrypt
Machine Learning
Scikit-learn Random Forest · 90%+ accuracy · 12 features
OCR Pipeline
PyTesseract · pdfplumber · Pillow
Frontend
Bootstrap 5 · Chart.js · Custom design system
Database
SQLite (dev) · MySQL (production)
Dataset
10,000 synthetic APU student records for model training
